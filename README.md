This project is a Backend API for an E-Commerce system built using ASP.NET Core Web API.

Key Features:
Full management for products, brands, and types.

Support for both Arabic and English localization.

Image upload capability.

Support for pagination, search, sorting, and filtering.

Basket management and caching.

Order management and delivery methods.

JWT authentication for user registration, login, and current user data management.

Deployment:
The project is deployed on MonsterASP server.

It uses a dedicated external server for Redis / In-Memory caching.

Architecture:
Built on a well-structured architecture based on the Repository Pattern, Unit of Work, and Service Layer to make development, maintenance, and scalability easier.
